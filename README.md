# AI-Based Resume Screening and Job Matching System

## Project Overview
This project is a Python-based application that analyzes resumes and compares candidates' skills with job requirements.

## Features
- Upload resumes in PDF format.
- Extract skills from resumes.
- Match resume skills with job requirements.
- Calculate matching percentage.
- Display matched and missing skills.
- Generate downloadable PDF reports.

## Technologies Used
- Python
- Streamlit
- PyPDF
- Regular Expressions
- ReportLab

## How to Run
1. Install the required libraries:
   `pip install -r requirements.txt`
2. Run the application:
   `streamlit run app.py`
